# Questions fréquentes

**Est-ce une application officielle ?** Non. Mon Parcours est indépendant du ministère de l’Intérieur. Le portail officiel et ses notifications font référence.

**Est-elle gratuite ?** Oui, sans publicité pour le moment.

**Faut-il un compte GitHub pour télécharger ?** Non. L’APK est hébergée sur GitHub Releases et se télécharge librement, sans connexion à GitHub.

**Pourquoi « service de versions injoignable » ?** Vérifiez votre connexion Internet puis réessayez ; GitHub peut aussi être temporairement indisponible. Une panne de ce service ne compte pas comme un échec de connexion ANEF et un premier fichier indisponible n’ajoute aucune restriction.

**Pourquoi les mises à jour ne s’installent-elles pas seules ?** Le bouton ouvre le téléchargement dans le navigateur. Android demande votre accord pour installer.

**Pourquoi mon dossier ne change-t-il pas ?** Une actualisation ne fait pas avancer le traitement administratif. Vérifiez la dernière synchronisation et les messages officiels. L’app n’invente pas de nouvelle étape.

**Pourquoi une rubrique est-elle indisponible ?** ANEF peut ne pas répondre à cette lecture ou la refuser pour votre compte. Ce n’est pas équivalent à « aucune demande ».

**Puis-je utiliser l’app hors connexion ?** Oui pour les informations conservées et les documents déjà téléchargés. Connexion, récupération de nouveaux messages et téléchargement nécessitent Internet.

**Pourquoi les notifications arrivent-elles plus tard ?** Android peut décaler le travail en arrière-plan. Vérifiez les autorisations de notification, le suivi automatique, les identifiants enregistrés, le réseau et la plage de silence.

**Que faire si Android refuse une mise à jour ?** Vérifiez la provenance, le nom de l’app et sa version. Une APK de développement utilise une autre identité/signature. Ne désinstallez pas l’application officielle comme première solution : vous perdriez ses données locales.

**L’app déposera-t-elle une demande pour moi ?** Non. Effectuez les démarches et modifications administratives sur ANEF.
